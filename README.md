# TI GAME / Overworld

Este é um projeto de jogo em desenvolvimento por um grupo de amigos, criado para testar ideias, exercitar lógica de programação/game design e construir algo divertido juntos.

O jogo combina mecânicas de exploração 2D top-down (estilo Overworld) com interação de computador/terminal baseada em cliques e comandos de mouse.

## Organização do Projeto

Para manter o repositório limpo e facilitar o trabalho em equipe no GameMaker Studio 2, padronizamos as pastas dividindo o escopo entre:

- Overworld: elementos do mundo explorável (cenário, NPCs, jogador e salas).
- Computer UI: mecânicas de interface do computador do protagonista (telas, ícones, arquivos e janelas).
- System / Core: controladores de áudio, save, inicialização e scripts globais.
